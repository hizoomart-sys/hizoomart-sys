# AIsberg

Full-stack разработчик. Делаю сайты, ИИ-ассистентов и автоматизацию для малого бизнеса.
Нахожу, где сервис теряет заявки.

**[«Рентген воронки»](https://github.com/hizoomart-sys/funnel-xray)**. Автоматизированная система анализа поведения пользователей:
показывает, на каком шаге и почему уходят клиенты.

Беру проекты на разработку и сопровождение, открыт к предложениям о работе.

## Что делаю

- **Лендинги с обработкой заявок:** заявка уходит в Telegram или CRM, оплата на месте
- **ИИ-ассистенты для заявок:** отвечают по материалам компании, сложное передают человеку
- **Автоматизация процессов:** учёт заказов, отчёты, связка сайта с CRM и таблицами
- **Сопровождение** после запуска

## Проекты

### [Фотоцвет](https://fotocvet.ru): обработка фотографий

Онлайн-сервис: восстановление старых снимков, оживление фото в видео, правки кадра.
15 000+ пользователей в месяц, 100 000+ обработанных фотографий, 1 300+ платящих клиентов.

Приём оплаты картой и через СБП, собственная авторизация, цепочки писем, сквозная
аналитика от первого захода до оплаты. [Кейс →](https://github.com/hizoomart-sys/fotocvet-case)

### [Фотокниги](https://fotocvet.ru/fotokniga): автоматизированный сервис печати

Человек собирает фотокнигу вручную или с помощью нейросети. Автоматические проверки
сопровождают заказ от загрузки фотографий до доставки.

Авто-раскладка разворотов, редактор книги, подготовка файлов к печати, отслеживание
заказа до вручения. [Кейс →](https://github.com/hizoomart-sys/fotokniga-case)

### [Agent Workflow Kit](https://github.com/hizoomart-sys/agent-workflow-kit): плагин для Claude Code

Как я веду разработку с ИИ-агентом: сессии переживают `/clear`, параллельные задачи идут
в отдельных ветках, а опасные действия и «готово» без проверки блокируются хуками до
выполнения. Открытый код с тестами. [Репо →](https://github.com/hizoomart-sys/agent-workflow-kit)
